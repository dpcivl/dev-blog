# mermaid 원본 보관소

`pnpm mermaid:render` 가 렌더할 때 mermaid 소스를 `<hash>.mmd` 로 여기에 한 벌
남긴다 (2026-11-14~). 해시는 소스 내용에서 나오고, 같은 해시의 SVG 가
`public/assets/mermaid/<hash>.svg` 에 있다.

## 왜 필요한가

렌더는 글의 ` ```mermaid ` 블록을 `<img>` 태그로 **치환한다.** 그 순간 원본이
글에서 사라진다. 2026-11-14 에 영어판 다이어그램을 만들려다 막혔다 — 발행된
24편 모두 원본이 어디에도 없었고 git history 에도 없었다 (항상 렌더 후에
커밋했으니 블록 상태로 들어간 적이 없다). SVG 만 남아서 번역할 재료가 없었다.

여기에 한 벌 남겨두면 언제든 다시 렌더할 수 있다.

## restored/ 는 다른 것이다

`restored/` 에 있는 31건은 **SVG 에서 거꾸로 복원한 것**이고, 이 폴더의
`<hash>.mmd` 와 성격이 다르다 — 파일명 해시와 내용 해시가 일치하지 않아
다시 렌더하면 다른 SVG 가 나온다. 섞지 말 것. 자세한 내용은
[restored/README.md](restored/README.md).

## 주의

- **직접 고치지 않는다.** 글의 mermaid 블록을 고치고 `pnpm mermaid:render` 를
  다시 돌리면 새 해시로 새 파일이 생긴다
- **`pnpm mermaid:gc` 는 이 폴더를 건드리지 않는다.** 참조가 없어진 `.mmd` 가
  남아도 그대로 둔다 — 용량이 작고, gc 는 2026-08-30 에 사용 중인 SVG 를 전부
  지운 적이 있는 자리라 손대지 않았다
- 발행 절차에서 **번역이 렌더보다 먼저**다. 순서가 뒤집히면 EN 글이 한국어
  그림을 참조한다 (CLAUDE.md 발행 절차 6·7번)
