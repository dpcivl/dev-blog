# SVG 에서 되살린 mermaid 소스

2026-11-14 이전에 발행한 다이어그램 31개를 **렌더된 SVG 에서 거꾸로
복원한 것**이다. 상위 폴더의 `<hash>.mmd` 와 성격이 다르니 섞지 않는다.

|                         | 상위 `src/data/mermaid/`       | 이 폴더                         |
| ----------------------- | ------------------------------ | ------------------------------- |
| 출처                    | 렌더할 때 저장한 **진짜 원본** | SVG 에서 거꾸로 복원            |
| 파일명 해시 = 내용 해시 | **그렇다**                     | **아니다** (31건 중 1건만 일치) |
| 다시 렌더하면           | 같은 SVG 가 나온다             | **다른 해시의 SVG 가 나온다**   |

## 왜 분리했나

이 파일들을 상위 폴더에 원본인 척 넣으면, 나중에 누군가 이걸 원본으로
믿고 다시 렌더한다. 그러면 **KO 글의 그림이 바뀐다.** 파일명이 가리키는
SVG 와 내용이 만들어내는 SVG 가 다르기 때문이다.

## 어디까지 맞는가

| 항목                            | 결과                                                         |
| ------------------------------- | ------------------------------------------------------------ |
| 라벨 (노드 · 엣지 · 서브그래프) | **31 / 31 일치**                                             |
| 엣지 수와 연결 관계             | **31 / 31 일치** (SVG 의 `data-id="L_A_B_0"` 에서 직접 읽음) |
| 노드 모양                       | 전수 확인 — 전부 사각형이었고 마름모 1개 · 저장소 모양 1개   |
| 렌더 결과 크기 (viewBox)        | 19 / 31 일치. 나머지는 서식·mermaid 버전 차이                |

복원이 가능했던 이유는 mermaid 가 SVG 에 구조를 남기기 때문이다.

```
id="mermaid-0-flowchart-D-0"   → 노드 id D
data-id="L_D_I_0"              → 엣지 D → I
```

서브그래프 4건과 `sequence` 1건은 자동 복원이 안 돼 손으로 썼다.
서브그래프는 각자 `<g class="root">` 안에 소속 노드를 품는 중첩 구조다.

## 무엇에 쓰나

**영어판 다이어그램의 번역 재료다.** EN 글 24편이 한국어 그림을 참조하고
있는데 (`alt` 만 영어로 번역됨) 원본이 없어 다시 렌더할 수 없었다.
이 복원본의 라벨을 영어로 바꿔 렌더하면 영어 그림이 생긴다.

레이아웃이 원본과 달라도 무방하다 — 영어로 바꾸면 글자 길이가 달라져
어차피 다시 계산된다.

## SVG 에 남지 않는 것 — 복원의 실제 한계

처음에는 viewBox 불일치 12건을 「서식·mermaid 버전 차이」로 봤는데, 실험해보니
**`direction` 누락**이 원인이었다. SVG 에는 그 정보가 남지 않는다.

```
graph-rag-01  원본 852x314 → 복원 294x936 (뒤집힘)
              subgraph 안에 direction LR 을 넣으면 831x314 ✓
graph-rag-02  원본 293x702 → 복원 1383x188 (뒤집힘)
              direction TB + 보이지 않는 연결(N ~~~ C) 을 넣으면 346x726 ✓
```

즉 **원본에는 `direction` 과 `~~~` 가 있었다.** 복원기가 못 읽은 것이다.
서브그래프가 있는 3건은 이 둘을 손으로 되살려 넣었다.

| SVG 에 남는가 | 항목                                                                             |
| ------------- | -------------------------------------------------------------------------------- |
| 남는다        | 노드 id · 라벨 · 엣지 연결 · 엣지 패턴(실선/점선) · 노드 모양                    |
| **안 남는다** | **`direction`** · **보이지 않는 연결(`~~~`)** · `style` · `classDef` · 선언 순서 |

아래 칸은 복원으로 알 수 없다. 레이아웃이 원본과 다르면 이쪽을 먼저 의심한다.
