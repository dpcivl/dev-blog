## 왜 시작했나

와이프와 처제 부부가 마인크래프트를 한다. 나는 게임은 하기 싫고, 그렇다고 마인크래프트를 하는 세 명과 너무 떨어지기도 싫었다. 그래서 Agentic AI 를 연습할 겸 마인크래프트 모드를 만들기 시작했다.

취미로 간단하게 만든 것이고, 바이브코딩으로 진행했다. 결론적으로 Agentic AI 를 사용해 간단한 방탈출 모드를 만들었다.

## 무엇을 만드는가

- Minecraft Java Edition 에서 4명이 함께 할 수 있는 게임. 방탈출, RP, 시뮬레이션 등을 계획하고 있다
- 그걸 만들 **모드 생성용 Agentic AI** — 기획서를 던지면 실 테스트까지 구현하게 한다
- 목표는 유명 유튜버들의 모드를 따라 해보는 것이다. 다만 내수용이고, 상업 목적은 없다

버전은 AI 가 잘 만들 수 있는 1.21.1 로 만들었다. Claude Sonnet 5.5 기준으로 자료가 많은 버전이다 (2026-10-10 기준). 모드는 Fabric API 를 사용해 만들었다.

## 에이전트부터 만들었다

가장 먼저 Agentic AI 를 만들어야 자동화할 수 있을 거라고 생각했다.

Agentic AI 를 위한 서브에이전트를 만든 뒤, HTML 을 서버에 띄워서 지금 어떤 에이전트가 작업 중인지 확인할 수 있게 했다. PixelOffice 를 레퍼런스로 삼았다.

- 오케스트레이터(메인 세션)가 지시를 듣고 해당하는 과정에 업무를 넘긴다
- 게임 설계 · API 조사 · 구현 · 빌드 및 테스트 · 4인 시뮬레이션 · 코드 리뷰 에이전트를 만들어서 진행했다
- 목표한 구현이 끝나면 알림이 와서 실 테스트를 하게 했다

중간에 실 테스트 관련 조작을 할 수 있도록 HTML 대시보드에 통합했다. 플레이테스트 실행 버튼을 누르고, 체크박스로 정상/이상 여부를 체크해서 테스트 결과를 남기기 쉽게 했다.

## 어디까지 했나

3시간 정도 개발했다.

- 4인 파티 기능 확인 완료
- 간단한 방탈출 퍼즐 기능 확인 완료 — 비밀번호 입력 퍼즐 · 색 순서 입력 퍼즐 · 동시 입력 퍼즐 · 힌트 제공 기능 외 기본 기능
- 방 3개짜리 간단한 방탈출은 구현했지만, 퍼즐 난이도가 너무 쉽다

구조물로 단서를 준다든가, 기존 방탈출 기믹을 AI 가 구현할 수 있는지 확인해보고 싶었다. 그래서 방탈출 기믹 레퍼런스를 찾아 구현해보라고 했고, 그 작업이 끝나서 지금은 실 테스트를 기다리는 상태다. 와이프와 처제, 처제 남편, 나까지 넷이서 실제로 테스트해보려고 한다.

서버를 열고 나와 와이프가 들어와서 플레이하는 것까지는 됐다. 하지만 4명이 파티에 들어와야 게임을 시작할 수 있어서, 게임 플레이 테스트는 아직 진행하지 못했다.

## 알게 된 것

### 역할별 에이전트는 써봤지만, 이렇게 자동화한 건 처음이었다

이전에 설계 · 구현 · 코드 리뷰 · 코드 품질 · 보안 담당 에이전트를 사용해서 개인 프로젝트를 한 적이 있다. 파이프라인을 만들어 진행한 적도 있었다. 하지만 이번처럼 메인 세션이 각 서브에이전트에게 일을 넘겨서 자동화한 적은 없었다.

나눠서 했던 경험을 살려서, 시각화하고 프롬프트를 구체적으로 작성해주면 될 것 같다는 생각이 들었다.

### 마인크래프트는 생각보다 구조물을 잘 만들었다

이전에 로블록스 플레이스를 만들 때는 오브젝트끼리 겹치거나, 좌표가 안 맞거나, 구조물이 컨셉과 안 맞는 일이 보였다. Luau 자료보다 Java 로 만드는 마인크래프트 자료가 많아서 그런지, 오늘 만든 게임 기준으로는 나쁘지 않은 퀄리티였다.

### 구현만 맡기지 말고 어떻게 구현되는지 봐야겠다

구현만 맡기는 것보다 어떻게 구현되는지에 좀 더 관심을 가질 필요가 있다는 걸 느꼈다. 회사 업무를 할 때처럼, 이것 역시 검증을 위해 어떤 결정이 내려지고 있는지 검토한다면 언젠가 써먹을 수 있는 개념이 나오지 않을까 싶다.

## 더 공부해볼 것

내가 하지 않는 일들을, 에이전트는 사람의 방식이 아닌 AI 의 방식으로 어떻게 검증할까?

- 구조물로 자신이 표현하고 싶은 걸 표현했을 때, 그게 맞는 방법인지 어떻게 아는가. 연구소를 표현하고 나서, 그게 연구소인 걸 어떻게 검증하나?
- 4명의 상태 관리를 서버 측에서 어떻게 다루고, 클라이언트 측에서 어떻게 동기화하도록 하는가?
