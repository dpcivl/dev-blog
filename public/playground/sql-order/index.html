SQL 절 순서 playground

SELECT · FROM · WHERE 는 적는 순서와 실행되는 순서가 다르다. 둘을 직접 만져보는 페이지.

1. 적는 순서 — 아무렇게나 놓으면 안 된다

절을 눌러 쿼리를 만들어보세요. 순서가 틀리면 실제 DB 가 내는 것과 같은 종류의 문법 에러가 납니다.

여기에 절이 쌓입니다…

2. 실행되는 순서 — FROM → WHERE → SELECT

같은 쿼리를 DB 가 처리하는 순서대로 한 단계씩 밟아봅니다.

SELECT ROUND(AVG(DAILY_FEE)) AS AVERAGE_FEE FROM CAR_RENTAL_COMPANY_CAR WHERE CAR_TYPE = 'SUV'
적는 순서
SELECTFROMWHERE
실행 순서
FROMWHERESELECT
CAR_IDCAR_TYPEDAILY_FEE
버튼을 눌러 단계를 진행하세요.

3. 그래서 WHERE 에서 별칭을 못 쓴다

SELECT 에서 붙인 AS AVERAGE_FEE 를 WHERE 에서 쓰면 왜 실패하는지 확인해보세요.
